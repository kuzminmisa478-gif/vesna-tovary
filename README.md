# Весенняя закупка из Китая: 50 товаров

Статический сайт-отборник: 50 мелких и лёгких товаров с 1688 под весенний спрос (март–май) на Wildberries и Ozon. Для каждой позиции указаны закупочная цена в юанях, цена на маркетплейсе, расчётная наценка, месяц пика, уровень конкуренции и риски (сертификация, маркировка, габариты).

Возможности:

- фильтр по категориям;
- сортировка по порядку, наценке, цене или месяцу пика;
- отметка товаров галочками (выбор сохраняется в браузере);
- копирование отобранного списка в буфер обмена.

## Структура

| Файл | Что внутри |
|---|---|
| `index.html` | Разметка страницы |
| `style.css` | Стили, светлая и тёмная тема |
| `data.js` | Список товаров — правьте здесь |
| `app.js` | Логика фильтров, сортировки и отбора |

Сборка не нужна: никаких зависимостей, только HTML, CSS и JS.

## Запуск локально

Откройте `index.html` в браузере. Или поднимите простой сервер:

```bash
python3 -m http.server 8000
```

и зайдите на http://localhost:8000.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите эти файлы в корень.
2. Settings → Pages → Source: **Deploy from a branch**, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет доступен по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

## Как поменять данные

Каждая строка в `data.js`:

```
[категория, товар, зачем, ¥min, ¥max, ₽min, ₽max, пик, конкуренция (1 — высокая, 2 — средняя), риск]
```

Курс юаня для расчёта наценки задаётся константой `RATE` в начале `app.js` (сейчас 11,5 ₽).

> Цены — ориентиры для отбора. Перед закупкой проверьте их в аналитике (MPStats и аналоги) и у поставщика.
